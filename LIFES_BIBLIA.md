## 🚀 ESTRATEGIA DE CRECIMIENTO VIRAL

### El motor principal: El Recuerdo Compartido

Cuando un usuario sube un recuerdo y etiqueta a personas:

1. **Notificación in-app** → Las personas con cuenta reciben aviso inmediato
2. **Mail con el recuerdo** → Las personas SIN cuenta reciben un email hermoso
   con el recuerdo, la foto, la dedicatoria — y una invitación a unirse
3. **Grupos de recuerdos** → El usuario puede crear grupos temáticos y compartir
   el recuerdo con todo el grupo de una sola vez

### Sistema de Grupos (feature prioritario)
Los grupos funcionan como listas de distribución emocional:
- 👨‍👩‍👧‍👦 **Familia** — para recuerdos del hogar
- ✈️ **Viaje a París 2023** — grupo de ese viaje específico
- 🎓 **Facultad** — compañeros de la universidad
- ⚽ **Deportes** — el equipo, el club
- 💼 **Trabajo** — colegas de una época

Cuando se crea un recuerdo en el Timeline, aparece la opción:
*"Avisar a un grupo"* → selector de grupos creados → todos reciben el recuerdo.

**El efecto viral:** Cada recuerdo compartido a un grupo de 8 personas
es una potencial invitación a 8 nuevos usuarios.

## 🎣 ESTRATEGIA DE MARKETING

### El gancho es HOY, no el futuro

❌ **No decimos:** "Preservá tu legado para cuando no estés"
✅ **Decimos:** "El viaje del fin de semana pasado. El cumpleaños de tu hijo. El partido de ayer. Guardalo en Life's antes de que el tiempo lo borre."

La bóveda, el testamento y los herederos son features secundarios en el marketing inicial.
Primero enganchamos con lo cotidiano y emocional.

### Canales prioritarios
1. **Tu Seguro Salud** — canal directo con personas que piensan en proteger a su familia
2. **Momentos de vida** — publicidad segmentada por eventos: nacimientos, casamientos, cumpleaños 40/50
3. **Boca a boca viral** — el mail de recuerdo compartido es el mejor anuncio
4. **Redes sociales** — contenido emocional, no técnico

## 🏗️ ARQUITECTURA TÉCNICA — Decisiones clave

### Stack elegido y por qué
- **Vite 4 + React + TypeScript** — velocidad de desarrollo + tipado seguro
- **SASS** — tokens de diseño consistentes, paleta Life's
- **React Router DOM** — 3 niveles de rutas: públicas / privadas / bóveda
- **Node.js + Express + PostgreSQL** — backend robusto y escalable
- **Lucide React** — íconos consistentes y livianos

### Paleta de diseño (inmutable)
```
Azul Noche:  #03192E  → identidad, profundidad
Crema:       #F5F0E8  → calidez, papel, memoria
Ámbar Dorado:#C9932A  → premium, legado, valor
Piedra:      #8A8279  → secundario, textos suaves
```

### Tipografías (inmutables)
```
Newsreader italic → títulos, frases, legado (serif emocional)
Manrope           → UI, labels, cuerpo (sans-serif limpia)
Mrs Saint Delafield → dedicatorias, cartas (caligráfica)
```

### Arquitectura de rutas
```
Públicas     → Landing, Login, CrearCuenta, TarjetaLegado
Privadas     → Feed, Perfil, Timeline, Árbol, Postal, Settings
Bóveda       → VaultRoute (triple seguridad obligatoria, sesión 15 min)
```

### La Bóveda — solo accesible desde el Muro Biográfico
La postal — solo accesible desde el popup de la Línea de Vida
